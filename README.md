# mini-agent-city

A small, interactive virtual city simulation featuring Mona, Karim, and Laila, their movements, memories, moods, relationships, and interactions.

## Run locally

Open `index.html` directly in a browser, or serve the project with:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- Live clock and adjustable 1×, 2×, and 4× simulation speed
- Pause and resume controls
- Three citizens with distinct locations and activity states
- Random travel and nearby conversations
- Energy, mood, memories, and relationship tracking
- Responsive interactive map
